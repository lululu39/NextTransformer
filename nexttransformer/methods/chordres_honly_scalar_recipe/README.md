# Position-only Chord gate with the original scalar constraints

The input to every gate is the weightless RMS-normalized position at that token, with epsilon 1e-6. For the projected coordinates plus the trainable biases, the effective controls follow the [static three-gain Chord](../chordres_velocity_gains/): direct signed mu, softplus for both position step sizes, sigmoid for old-velocity retention, and direct signed parallel/perpendicular displacement gains. The previous readout initialization gives effective controls (0, 0.05, 0.05, 0.5, 0.5, 0.5) with zero gate weights. The terminal MLP retains its three active position/read controls. Physical velocity still participates in the lookahead and tangent write. Both the activations and their derivatives are fused into the position-only Triton read kernel.
