# mHC with nanochat-style routing, matched random branch outputs and learned readout

This fresh test is the single mHC comparison to the [random-projection ChordRes run](https://wandb.ai/yibozhong657-none/nexttransformer-chordres/runs/1879c1a2). It uses the [50M nanochat mHC architecture reference](https://github.com/yibozhong/nanochat/blob/8ffcee04fa5bb697394021fb0471450f82e28c2d/nanochat/nvidia_connections.py) for four-stream routing, learned readout and initialization. The official Standard Residual local reproduction was stopped at logged step 610, after checkpoint 500.

The NextTransformer mHC shell retains 23 layers, width 1,536 and FFN width 6,016 (the ChordRes comparator uses 6,144). Allocate separate seed streams for routers at initialization. Initialize ordinary attention-output and FFN down projections with projection seed 43 and std 0.02/sqrt(46), as in the ChordRes experiment. Both methods use base seed 42, BF16, 2,048 context, global batch 1,048,576 tokens, microbatch 8 on eight GPUs, accumulation 8 and the native 46,875-step optimizer schedule. All router and final-readout parameters use the NextTransformer auxiliary AdamW group. The [method and comparison details](../../nexttransformer/methods/mhc_nanochat_readout/README.md) include numerical implementation scope.

Run the [calibrated configuration](../../configs/residual/mhc_nanochat_readout.json) via the matched-normal research entry point. Verify the actual eight-GPU forward, backward and optimizer updates before the fresh run. The training segment ends after 8,000 steps (8,388,608,000 input tokens), validation, full-context CORE-22 and a complete checkpoint. W&B display name: `mhc-nanochat-router-readout-matched-normal-8k-seed42` in [the ChordRes project](https://wandb.ai/yibozhong657-none/nexttransformer-chordres). Compare with both the local ChordRes run and the published native mHC curve. Combined changes to projection initialization, routing, and final readout are evaluated together.

This mHC training was cancelled before its GPU preflight and first update. The replacement experiment changes the [ChordRes control learning rate](2026-11-23-chordres-control-lr-8k.md).
