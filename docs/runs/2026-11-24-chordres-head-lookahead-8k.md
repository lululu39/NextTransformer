# ChordRes with a terminal lookahead

Train from scratch against the [VE-on, high-control-LR ChordRes reference](https://wandb.ai/yibozhong657-none/nexttransformer-chordres/runs/13fb5703). The single new parameter is a zero-initialized, unconstrained scalar rho in the final velocity read. The head consumes RMSNorm(h_last + rho * v_last) after the terminal MLP write. The original 46 sublayer controls, fixed terminal retention of 0.5, native final normalization, LM head and logit softcap are preserved. Both attention and FFN run the saved-force kernels.

Both experiments have 23 full-attention layers, width 1,536, FFN 6,144, input smear, 12 attention value embedding tables, and zero initial velocity. The 184 control entries (the original 183 plus rho) use AdamW peak LR 0.0024494897427831783 with zero weight decay. Shared tensors use seed 42 and matched-normal branch output projection seed 43. Eight GPUs run per-rank microbatch eight with eight accumulation steps, context 2,048 and 1,048,576 tokens per update. Keep the 46,875-update optimizer schedule and stop after step-8,000 validation, full CORE-22 and checkpoint.

Use the [terminal-read configuration](../../configs/residual/chordres_head_lookahead.json) through the high-control-LR research launcher. The local and W&B scalar readback accompanies the training curve. The reference ended at step 4,000 (BPB 0.79343645), so the directly matched comparison covers the common prefix. The [no-attention-VE run](https://wandb.ai/yibozhong657-none/nexttransformer-chordres/runs/7651aae9) was stopped at logged step 1,170 and retained checkpoint 1,000; it is a separate comparison.
