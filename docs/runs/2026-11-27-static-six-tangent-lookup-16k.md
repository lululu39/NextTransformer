# Six static controls versus h-dependent controls at 16k

Compare the [static six-control configuration](../../configs/residual/chordres_static_six_lookup.json) with [the clean dynamic tangent lookup run](https://wandb.ai/yibozhong657-none/nexttransformer-chordres/runs/3ac13380). Both use six control roles, with unused final velocity coefficients fixed. The static variant learns 273 scalars across depth. It removes 419,328 h-dependent projection weights and 137 modulation scales from the dynamic model. All retained parameters have identical optimizer settings, including the 0.000848528137 peak LR of the static control logits and the 0.30 peak LR of the velocity table.

Start both from seed 42 with native zero output projections, the same zero-initialized token velocity lookup, simple tangent projection, soft force τ=0.05, attention value embeddings and smear. Use the same 23-layer, width-1,536, FFN-6,144 BF16 model, ClimbMix stream, 2,048 context, eight H100s, microbatch 8 and eight accumulation steps. Train from scratch on the original 46,875-step LR schedule through step 16,000 (16,777,216,000 input tokens). Evaluate validation BPB every 250 steps and full CORE-22 at 8,000 and 16,000 using the same 2,048-token context cap. Keep the complete step-16,000 checkpoint for possible continuation.

The [reference compute audit](../../evidence/costs/chordres-static-six-lookup-v1/chordres_static_six_lookup.json) counted 1,406,142,489 parameters and 4.684018 GFLOPs per input token (+0.249% versus the anchor). BF16 forward and backward for the scalar read matched the token-conditioned site with the dynamic projection zeroed. A bounded eight-rank sharded synthetic forward and backward at the full width and depth verified finite loss and gradients and matched optimizer settings for all shared parameters.
