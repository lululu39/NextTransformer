# Native-zero Chord with learned mixing scales, 8,000 updates

The [fixed-scale run](https://wandb.ai/yibozhong657-none/nexttransformer-chordres/runs/faea35e6) completed 2,000 updates at 0.810722 BPB, versus 0.812241 for [static three-gain Chord](https://wandb.ai/yibozhong657-none/nexttransformer-chordres/runs/a710a057). The new research run starts fresh and follows the official NextTransformer mHC initialization convention for the dynamic projection and scale. It retains Chord's original position and velocity equations.

Use native zero attention output and MLP down projections. Each normalized pre-sublayer position predicts six logit corrections (three in the final MLP). Dynamic projection weights start at zero. Lookahead, position and velocity each receive a learned modulation scale initialized at 0.01 per site, with only the first two present at the final MLP. Static biases use AdamW peak LR 0.0024494897427831783. The 419,328 projection weights and 137 new scale entries use peak LR 0.000848528137423857. Both groups retain the existing optimizer settings and 40-step warmup. Log effective control dispersion and the mean learned scales for the three families at validation. The fused Triton read computes gradients for both the projection and the scales, including zero scales.

The model uses 23 blocks, width 1536, FFN 6144, full attention, 12 native VE tables, input smear, zero initial velocity and the ordinary LM head. Use the previous environment, ClimbMix data revision and data order, seed 42, eight H100 ranks, B8, eight accumulation steps and 2,048-token context. Train for 8,000 updates (8,388,608,000 input tokens) on the 46,875-update schedule. Retain the existing gradient stop. Run BPB each 250 updates and full CORE-22 with 2,048-token evaluation context at 8,000, then save the resumable checkpoint. The model has 1,356,230,306 parameters and 4.687259 theoretical training GFLOPs per input token (0.318% above the anchor). The fixed-scale reference used random branch output projections, so a performance difference combines the learnable scales and the change in branch initialization.
