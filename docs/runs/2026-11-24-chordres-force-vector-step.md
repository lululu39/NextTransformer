# Position-step gate reads the full attention or MLP branch vector

For each token use alpha = softplus(b + dot(w, F)) with one D-dimensional projection per sublayer. F is the raw force vector in the gate. Its unit-RMS direction is used in the position update. Mu and beta remain static and the velocity write uses complementary beta weights. Equal-RMS inputs can produce different alpha values depending on orientation. The previous [amplitude-only experiment](https://wandb.ai/yibozhong657-none/nexttransformer-chordres/runs/94bbad09) used just a scalar function of the power; it stopped after logged update 330 following clarification of the intended gate input.

Preserve zero-initialized attention outputs and MLP down projections, a zero-initialized gate vector, initial alpha 0.05, mu 0 and beta 0.5, seed 42, the single unsplit position update, 23 layers, width 1,536, FFN 6,144, smear, 12 value-embedding tables and saved BF16 forces. All Chord parameters use the mHC auxiliary AdamW peak 0.000848528137423857 (betas 0.9, 0.95, zero decay). Run 2,000 updates on the same ClimbMix stream and 46,875-update LR schedule, with 2,048 context, eight H100 ranks at B8 with eight accumulation steps. Validate BPB every 250 steps and preserve the standing gradient stop and GPU holds. The h-only three-control run also made mu and beta token-dependent; that comparison changes both their conditioning and the position-step input.
