# Official NextTransformer mHC with only attention VE removed

Start from scratch on seed 42 using the [native mHC implementation](https://github.com/Interactive-Active-AI/NextTransformer/blob/b2ea46627f7d0d5c9ef57a655c43b553558417d3/nexttransformer/models/lm.py#L253-L261), the [official mHC geometry](../../configs/residual/mhc.json), the native optimizer, and the [VE-off ablation config](../../configs/residual/mhc_official_no_ve.json). The 12 per-layer token-value tables and 12 associated gates are removed. The 23-layer, width-1,536 shell uses FFN 6,016, input smear, zero output projections, native mHC routing bias/initialization and native sum readout. The declared native router AdamW base LR is 0.0006 (peak 0.000848528137423857 after batch scaling). No special initialization or optimizer launcher is used. The public mHC implementation uses log-space Sinkhorn; the published historical run switched to it at 31,500 updates.

Every retained parameter and its optimizer settings are matched against a native VE-on mHC built on the same GPU at the same seed. Additional checks use nonzero output projections in a diagnostic model to verify logits and shared gradients when the native VE outputs are zeroed. The training run uses the original zero output initialization.

Use eight H100 GPUs, per-rank microbatch eight, eight accumulation steps, BF16, 2,048 context, 1,048,576 tokens per update, the same ClimbMix data, and the native 46,875-update schedule. The segment ends after step 8,000 validation, CORE-22 and checkpoint. The W&B display name is `official-mhc-no-attn-ve-8k-seed42`. Compare with the published official VE-on mHC curve and the local no-VE Standard/Chord curves (random branch initialization, observed through update 1,000). The superseded nanochat-style mHC run was stopped at logged step 140.
